# Portfólio Encadernado

Modelo 3D do meu portfólio de carreira encadernado em wire-o, para a gráfica visualizar o acabamento.

**Abrir:** https://victin7.github.io/Portfolio-Encadernado/

- 1 unidade · A4 75 g/m² · impressão colorida, só frente · 38 folhas
- Wire-o 3:1 · 5/16" (7,9 mm)
- Capa de acetato transparente · contracapa PP preto fosco

O conteúdo das páginas está desfocado de propósito: o arquivo para impressão será entregue em PDF.
